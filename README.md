# SkillSync

### Learn from someone. Teach someone. Grow together.

SkillSync is a campus peer-to-peer skill exchange platform that helps students discover each other based on the skills they can teach and the skills they want to learn.

## 🚀 How It Works

1. Create your profile
2. Add skills you can teach
3. Add skills you want to learn
4. Discover other students
5. Find complementary matches
6. Exchange skills

## 💡 Example

**Student A**

Can teach:
- Python
- React

Wants to learn:
- UI/UX

**Student B**

Can teach:
- UI/UX

Wants to learn:
- Python

SkillSync identifies this as a potential reciprocal match.
